# 导航

Omarchy 强调键盘驱动的工作方式：大多数操作通过组合快捷键完成，而鼠标只在特定情境下辅助使用。以下是常用的导航与窗口管理要点：

- 启动与菜单
	- Super + Space：打开应用启动器。
	- Super + Alt + Space：打开 Omarchy 菜单（系统配置、安装等）。

- 启动常用程序
	- Super + Return：打开终端。
	- Super + Shift + B：打开浏览器。

- 窗口布局与管理
	- Super + J：将活动窗口切换为水平堆叠布局；再次按可返回原始排列。
	- Super + Shift + Arrow（方向键）：在不同窗口或工作区间移动窗口位置。
	- Super + T：切换窗口在瓦片与浮动模式间；再次按恢复。
	- Super + F：窗口全屏；Super + Alt + F：保持顶栏但让窗口全宽。
	- Super + W：关闭当前窗口。

- 分组与标签页
	- Super + G：将窗口加入/移出分组；分组内的窗口可以通过 Super + Alt + Tab 或 Super + Alt + 1/2/3/4 快速切换。

- 工作区
	- Super + 1/2/3/4：切换工作区。
	- Super + Shift + N：将窗口移动到指定工作区（例如 Super + Shift + 2）。

鼠标在 Omarchy 中仍然有用：按住 Super 并左键拖动可以重新排列窗口；按住 Super 并右键拖动可自由调整大小。

这些键位和行为可以通过 Hyprland 的配置文件进一步自定义。熟悉这些快捷键后，你会发现基于键盘的操作更快、更连贯。更多示例截图和组合键请参阅手册原文。
