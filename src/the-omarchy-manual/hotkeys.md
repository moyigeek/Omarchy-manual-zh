# 快捷键

在 Omarchy 中查看所有主要绑定：按 Super + K。
在 Omarchy 中，你可以通过按 Super + K 来查看所有主要快捷键。下面按功能分组列出一些常用绑定（节选）：

导航

| 快捷键 | 说明 |
|---|---|
| Super + Space | 打开应用启动器 |
| Super + Alt + Space | 打开 Omarchy 菜单 |
| Super + Escape | 锁屏 / 挂起 / 重启 / 关机 |
| Super + W | 关闭当前窗口 |
| Super + T | 在瓦片和浮动窗口之间切换 |
| Super + F | 全屏 |
| Super + Alt + F | 全宽（保留顶栏） |
| Super + Arrow | 将焦点移动到指定方向的窗口 |

启动应用

| 快捷键 | 说明 |
|---|---|
| Super + Return | 终端 |
| Super + Shift + B | 浏览器 |
| Super + Shift + N | Neovim |
| Super + Shift + D | 启动 LazyDocker |
| Super + Shift + O | 打开 Obsidian |

全局剪贴板与捕获

- Super + C / X / V 为统一的复制/剪切/粘贴键（适用于大多数环境）。
- 截图与录屏通过 Print Screen、Shift + Print Screen、Alt + Print Screen 等组合进行，配合 Omarchy 的截图工具可直接编辑或保存到剪贴板。

样式与切换

- Ctrl + Shift + Super + Space：选择新主题
- Ctrl + Super + Space：切换下一个背景图片
- Super + Backspace：切换窗口透明度

快速表情与自动补全

- 支持通过 CapsLock 为前缀的快速表情快捷键集合，以及 CapsLock + Space + Space 等快速补全项（可在 `~/.XCompose` 中自定义）。

注：所有快捷键都可以在 `~/.config/hypr/bindings.conf` 中修改以适配个人习惯。完整按键表见原手册的 Hotkeys 页面。
