# 主题

Omarchy 自带多套精心设计的主题，用户可以通过菜单（Style > Theme）或快捷键（Super + Ctrl + Shift + Space）快速切换。

每个主题会统一风格化桌面、终端、Neovim、活动屏（btop）、通知（mako）、顶部栏（waybar）、应用启动器（walker）以及锁屏界面（hyprlock）。部分主题还包含一组背景图片，可用 Super + Ctrl + Space 在背景间循环切换。

想要更多风格可以访问「额外主题」章节或自己创建主题（参考「制作自定义主题」）。

示例主题包括：Tokyo Night、Catppuccin、Everforest、Gruvbox、Nord 等。
