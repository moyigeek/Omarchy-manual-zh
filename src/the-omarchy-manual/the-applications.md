# 应用程序

本章概述 Omarchy 预装或易于安装的主要应用程序类别，并介绍如何通过 Omarchy 菜单或快捷键访问它们。系统默认将常用工具与主题集成，以便在不同程序间获得一致体验。

示例应用包括：浏览器（Chromium）、终端与终端编辑器（Alacritty、Neovim）、笔记工具（Obsidian）、媒体播放器（Spotify）、与若干实用工具（btop、LazyDocker）。

许多应用都绑定了快捷键（见 Hotkeys），且部分应用会随主题自动调整外观（例如 Neovim 与 Obsidian 需要单独在各自设置中选择主题以获得完全一致性）。

欲了解单个应用的使用建议和常见配置，请跳转到对应子章（例如 `neovim.md`）。
