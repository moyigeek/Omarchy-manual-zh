# 欢迎来到 Omarchy

Omarchy 是一个基于 [Arch Linux](https://archlinux.org/) 和平铺窗口管理器 [Hyprland](https://hypr.land/) 的 [omakase](../Omacom/omakase-computing.md) 发行版。它包含了现代软件开发人员提高工作效率所需的一切，从 [Neovim](https://neovim.io/) （顺便说一下）到 Spotify，从 Chromium 到 [Typora](https://typora.io/) ，从 [Alacritty](https://alacritty.org/) 到 LibreOffice。甚至连 Zoom 也包含在内！

不过，这不仅仅是一堆预装软件包的杂牌。它是一个兼顾美观和效率的完整系统。因为优美的系统是一种能够激发动力的系统，而[生产力始终源于动力](https://world.hey.com/dhh/beautiful-motivations-6fef7c73)。这里没有任何臃肿的东西：所有我常用的东西都包含在内。

诚然，要培养对 Omarchy 这样一款 TUI 丰富、主题丰富、窗口平铺管理的系统之美的鉴赏力，可能需要后天培养。但这正是你来这里的目的，不是吗？想体验一些略微超出你舒适区的东西？想开启一段探索全新电脑工作方式的冒险？我希望如此。

Omarchy 既不像 Windows，也不像 macOS。它并没有刻意追求尽可能的熟悉。它力求美观和卓越 。拥抱它的一切 Linux 特质。当然，需要手动编辑一些配置文件。而且肯定会占用大量终端资源。

让我们从基础开始。
